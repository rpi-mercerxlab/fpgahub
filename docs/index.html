FPGAHub: VLSI Repository Version Control and IP Management Using Semantic Tree Differencing

Authors: Ryan Berube, Lauren Kelly, Shayla Sawyer Armand

View / Download PDF GitHub Repository

Abstract

Field Programmable Gate Array (FPGA) and Very-Large-Scale-Integration (VLSI) projects are often highly modular, hierarchical, and depend frequently on module reuse. Despite this, repositories of modules are often treated as flat text files, relying on line-by-line difference based tools for version control. This methodology does not always capture the structural significance of changes within a project. To bridge this gap, we introduce FPGAHub, an open-source tool for managing a repository of modules through semantic differencing. Through representing projects as Directed Acyclic Graphs (DAGs), FPGAHub maintains one central repository DAG and adapts the Gumtree Abstract Syntactic Tree (AST) differencing algorithm to generate semantic edit scripts. Through pre-processing steps to adapt this algorithm, we introduce a methodology for managing hierarchical changes across a repository. We evaluate FPGAHub against Git in compute performance and difference representation, showing practical resource usage and effective structural change representation. Ultimately, FPGAHub replaces fine grain line-by-line detail with a structural, high-level focus, aligning version control directly with hardware semantics.
